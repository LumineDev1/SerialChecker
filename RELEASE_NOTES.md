## Serial Checker 2.0.2

### Changed: exports always include every check

**Export results** in the Compare window (or **Ctrl+E**) now saves the full comparison every time: every check from every category, in both the text report and the CSV. The report's pass rate and outcome counts cover all checks too.

The **Important** and **All values** tabs, the outcome filters, and search now only change what's on screen. Before, an export saved just the checks you were looking at, so an export taken with a filter on (for example only **Attention**) left the rest out.
